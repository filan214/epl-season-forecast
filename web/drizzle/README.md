# Migrations

Drizzle owns the schema (`../src/db/schema.ts`). These SQL files are the
migration history applied to Neon Postgres.

| File | What it does |
|---|---|
| `0000_init_schema.sql` | All seven tables, three enums, foreign keys, and the four indexes. Generated by `drizzle-kit generate` from `schema.ts`. |
| `0001_leakage_guard.sql` | **Hand-written.** The `BEFORE INSERT` trigger enforcing `predictions.created_at < matches.kickoff_utc`. Drizzle cannot express a cross-table constraint, so this is a custom migration. See PRD.md §6.5/§13. |

`meta/` holds Drizzle's journal and per-migration snapshots — do not edit by hand.

## Apply

```powershell
# from web/, with DATABASE_URL set in .env.local
npm run db:migrate
```

`db:migrate` runs both files in order (0000 then 0001).

## Regenerate after a schema change

```powershell
npm run db:generate   # diffs schema.ts, writes the next 0002_* migration
```

Never rewrite `0000`/`0001` after they have been applied — add a new migration.

## Verify the leakage guard (checkpoint P0)

```powershell
# rejects a prediction dated at/after kickoff; leaves no data (rolls back)
psql "$env:DATABASE_URL" -f scripts/verify_leakage_guard.sql
```

Expected tail: `PASS: leakage guard verified.`
